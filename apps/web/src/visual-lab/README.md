# Визуальная лаборатория

Изолированный development-only экран: `http://localhost:5173/#visual-lab`.
Откройте адрес напрямую или перезагрузите страницу после изменения фрагмента.
В production маршрут недоступен, модуль и его ресурсы исключаются из сборки.

Варианты DOSSIER, FIELD ARCHIVE и EXPEDITION TERMINAL используют один компонент,
общие mock-данные и общее состояние навигации. Действия меняют только локальный
предпросмотр. Запросов к API, работы с токенами и пользовательскими файлами нет.
На широком экране варианты сравниваются рядом, на узком — последовательно.

`assets/mira.png` — временный портрет вымышленного персонажа, созданный встроенным
image_gen, не пользовательский upload. Шрифты системные, загрузок из сети нет.
Портрет общий для трёх вариантов; весь интерфейсный текст остаётся HTML.

Промпт портрета: documentary archival head-and-shoulders photograph of fictional
adult female northern ranger Mira Voss, short dark hair, calm alert expression,
practical charcoal outdoor jacket, neutral gray studio wall, soft natural light,
muted realistic colors, square framing with cropping room; no weapons, text,
logos, UI, borders or watermark.

Лаборатория не выбирает оформление и не переносит его в рабочий интерфейс.

## Доработка Field Archive

Вариант B имеет переключатель «B1 Исходный / B2 Доработанный» под предпросмотром.
По умолчанию показан B2. B1, A и C сохраняют прежнее оформление и данные.
Новые стили ограничены классом `vl-b-refined` в `field-archive.css`.

B2 исследует универсальный Dark RPG Codex, а не детективное досье.
Сохранены композиция, светлая поверхность внутри тёмного shell и пять разделов.
Убраны штампы, номера дела/фотографии/вкладок и канцелярская типографика.
Основной текст — 15–16 px, вторичный — 13–14 px, метаданные — 12 px;
имя — 30 px, заголовки — 23 px. Дата «18 сентября» — mock-пометка.
Портрет прежний; новые файлы изображений и шрифтов не добавлялись.
Шрифты B2: Georgia для заголовков, Arial для текста и метаданных.
Отдельно показаны основа интерфейса и примеры акцентов атмосферы кампании.
Это статические образцы токенов, не переключатель тем. Акцент используется
через переменную `--vl-accent` и не определяет структуру интерфейса.

## Компоновка Player в B2

B2 держит название ProgDM и сессии сверху, а пять разделов — снизу.
Центральная область прокручивается отдельно. Hero персонажа присутствует
только на Главной и в Профиле. Главная показывает до трёх новых событий,
Инвентарь — реестр из трёх mock-предметов, Знания — отдельные записи с типом.
В Журнале вкладки «Хроника» и «Мои заметки»; Профиль содержит read-only карточку
и локальный mock-режим редактирования. Заметки и профиль существуют только
в состоянии Visual Lab и сбрасываются при перезагрузке страницы.
